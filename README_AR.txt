تطبيق أشرف أرتين - مشروع APK

هذا المشروع يبني تطبيق أندرويد يفتح نظام الورشة المنشور على Streamlit داخل WebView.
يحتاج التطبيق إلى اتصال بالإنترنت. لا يحتوي على قاعدة بيانات محلية ولا ينسخ بيانات Supabase.

طريقة البناء:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub.
2) افتح تبويب Actions.
3) شغّل Build Ashraf Artin APK أو انتظر اكتمال البناء بعد Push إلى main.
4) افتح نتيجة التشغيل الناجح ثم Artifacts ثم Ashraf-Artin-APK لتنزيل APK.

هذه نسخة Debug للتجربة والتثبيت اليدوي، وليست إصدارًا موقّعًا للنشر على Google Play.
